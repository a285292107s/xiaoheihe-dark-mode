# 深色引擎：为什么长这样

这份文档讲 [`src/dark-engine.ts`](../src/dark-engine.ts) 的架构决定与取舍。
完整证据链（含每条结论的复现命令与实测数字）在 [`research/FINDINGS.md`](../research/FINDINGS.md)。

## 两条实测结论决定了整个架构

1. **站点的设计令牌层对渲染是失效的。** 站点定义了 695 个自定义属性（`--hb-*`、`--hb-general-color-*`），
   但把它们全部改成刺眼的红色后，页面上 **0 个元素变色**。真正决定外观的是
   546 条含字面量颜色的规则 —— 所以必须处理字面量，只覆盖变量是空转。
   （Element Plus 的 `--el-*` 令牌是例外，它确实生效，已单独补齐暗色值。）
2. **逐元素写内联样式有三处结构性死角。** 伪元素无法施加内联样式（站点有 426 条规则作用于
   `::before`/`::after`/`::placeholder`）；交互态无法用内联样式表达；SPA 会持续变更 DOM。
   而 CSS 规则天然作用于「当前与未来所有节点，含伪元素与各交互态」。

因此引擎的流程是：读站点样式表 → 判定每条声明的颜色角色（表面 / 文字 / 边框 / 阴影）→
**就地改写站点声明本身**（`CSSStyleDeclaration.setProperty`），层叠顺序、条件块、
原来的 `!important` 全部原样保留。关键帧与内联样式另行就地处理。

## 映射是单调的，不做取反

表面按四档压进深色带：画布 `#0b0e12` → 面板 `#11151b` → 浮起面 `#171c24` → 覆盖层 `#1d242e`。
原色越亮映射越高，白色卡片在白底页上的层级因此保留下来。
文字走三档中性色（`#e6eaf0` → `#a4aeba` → `#7f8b99`），彩色文字只保留色相、压掉饱和度。
边框统一改成白色低透明度细线，原色越深线越实。取反会丢掉层级关系，页面会变成一片均质灰。

## 调色板只有一个来源

四档表面与三档文字写在 `src/dark-base.css` 的 `html.hb-dark` 上（`--hbd-canvas` / `--hbd-surface` /
`--hbd-raised` / `--hbd-overlay` / `--hbd-ink` / `--hbd-ink-muted` / `--hbd-ink-soft`）。
引擎在每次构建前读这些令牌，`dark-engine.ts` 里的 `PALETTE_FALLBACK` 只在令牌缺失时兜底。
例外层、Element Plus 令牌与评论区共享令牌都引用同一批 `--hbd-*`，不再各写一套灰。
改配色只改 `dark-base.css` 这一处；关掉开关时令牌随基础层一起撤除，站点回到原样。

## 不追加 `!important`

站点有两条优先级完全相同（`(0,2,1)`）、靠先后顺序决定胜负的规则，抢赢站点自己的 `:hover`
规则就会把半透明覆盖层换成不透明板 —— 这正是 `research/FINDINGS.md` 第十节记录的缺陷。
引擎因此绝不擅自追加 `!important`，靠提高选择器权重（自己的类名前缀）取胜。

## 想自己调配色

改 `src/dark-base.css` 里 `html.hb-dark` 的 `--hbd-*` 令牌即可，其余映射都从它们插值：

```css
--hbd-canvas: #0b0e12;
--hbd-surface: #11151b;
--hbd-raised: #171c24;
--hbd-overlay: #1d242e;
--hbd-ink: #e6eaf0;
--hbd-ink-muted: #a4aeba;
--hbd-ink-soft: #7f8b99;
```

对比度下限：正文对浮起面不低于 4.5:1，次要文字不低于 4.5:1，装饰性细线不承担信息。
改完跑一遍 `pnpm run build`。

## 例外层

引擎对绝大多数声明是「就地改写」，但仍有一层少量人工例外：导航主 CTA（登录 / 发布）
的反相填充、深色下撤掉两处浅色 `box-shadow` 边界（搜索框与信息流图片），
以及把站点用渐变画的按钮压成单色填充。

渐变按钮一律走「`background-image: none` + 单一 `background-color`」：站点在
`linear-gradient(46deg, #464b50, #14191e)` 这类品牌黑上叠白字，深色主题里这层渐变
已经被压到与卡片几乎同亮度，只剩一条读不出方向的脏边。次级控件统一填 `--hbd-hover`，
导航主 CTA 填 `--hbd-paper` 配 `--hbd-paper-ink` 的深色字；按钮文字色沿用站点声明，不再另配。

例外层没有 `!important`，选择器必须逐条压过站点原规则，所以每条都按站点的完整
选择器路径书写（含 `[data-v-*]` 作用域属性）。站点改类名或换作用域哈希时，对应规则
会静默失效、渐变原地回来 —— 不报错，只是看起来「没生效」。等级标签、点赞数的渐变
文字、颜色选择器、骨架屏、分页渐隐与轮播阴影不属于按钮，保持原样。

这些例外各自「为什么是必要的」与「撤掉之后边界改由什么承担」记在
[known-limits.md](known-limits.md#深色引擎)。
