# 参考页分析：另一家的暗色评论区 → 我们采用了什么

素材：一张暗色评论区的截图（用户提供，2026/10/04 的帖子，主楼 15 楼带 4 条楼中楼）。
截图里出现的是「IT之家四川成都网友 / IT之家广西南宁网友」，所以**那不是小黑盒**——
本文件借的是它的**信息架构**，不是它的配色与组件实现。

这份笔记只回答两件事：那页做对了什么、我们这一轮照做了什么、以及**为什么不照做**另几条。
落地判据在 `scripts/verify-cards.mjs` 的分组二 / 分组二·补 A / 分组二·补 B。

---

## 1. 那页的事实（逐条对着截图抄）

1. **两级评论用同一套语法。** 主楼与每条楼中楼都有同一条右对齐的动作行
   （`举报 支持(N) 反对(N) 回复`），支持绿、反对红，0 也照写。
2. **每条楼中楼带稳定编号**：行右上角 `1# 2# 3# 4#`。
3. **回复对象引用那个编号**：`回复1# 独眼x巨人：国道能跑到CLTC`。
   编号与名字在同一行、同一段里（回复对象是灰的、正文是白的，不换行）。
4. **回复对象永远写出来**：包括回复楼主的情形 —— 页面上不会出现孤零零一个冒号。
   只有楼中楼第一条（1#，本来就是楼内第一条）不带回复对象。
5. **等级牌 `Lv.75 / Lv.78`** 挂在头像下方那一列，两级评论都有。
6. **主楼动作行最左是「折叠」**：把整条楼中楼收起，长楼不再淹没版面。
7. 时间给的是绝对时间戳（`2026/10/04 18:23:22`），IP 归属地跟在作者名后
   （`IT之家广西南宁网友`）。
8. 暗色配色：页面近黑，卡片比页面亮一档，靠 1px 描边 + 小圆角成形，meta 文本统一压到中灰。
9. 楼中楼**整组**包在一个有描边、略浅的容器里，容器内每条是一张卡 —— 层级一眼可读。

## 2. 采用情况（照做 / 不做，都写理由）

| 参考页做法 | 小黑盒这边的现状 | 判断 | 本轮落地 |
| --- | --- | --- | --- |
| 每条回复一个稳定编号 `N#` | 楼中楼 DOM 没有任何序号 | **采用** | `.hb-tc__floor`：序号由 DOM 位置算出（不依赖接口），第一行右端 |
| 回复对象引用编号 | 站点 42 条里 26 条只渲染出一个 `:` | **采用（能定位时）** | 接口 `replyid` 能在同楼定位到那条卡片时，写「回复 #N 名字」，N 就是那张卡片的序号 |
| 回复对象永远写出来 | 26/42 条是悬空冒号，读不出在回谁 | **采用** | 目标是楼主时写「回复楼主」（**不重复名字**，卡片上方就是那位楼主） |
| 长楼可折叠 | 站点没有折叠入口（真机单楼能有 21 条回复） | **采用** | 一级评论操作条里的「折叠 / 展开 N 条」，折叠只给容器加一个类 |
| 时间 / IP 与作者同一行 | 小黑盒**主楼自己**的版式是「作者一行、时间/IP 在下一行」（`.info-box__line-2`） | **不照搬**（用户反馈后定的） | 卡片里时间/IP 独占一行：同一行时它紧跟在「回复对象：」后面，读成「回复楼主：9小时前·安徽」 |
| 等级牌 `Lv.N` | 站点只给**主楼**渲染 `.level-tag`；楼中楼 DOM 里没有，接口里 11 条楼中楼的 `user` 也没有 `level_info` | **不采用：拿不到数据** | 记录在 README 的已知限制；不猜、不编 |
| 支持 / 反对计数 | 楼中楼接口有 `up`，但真机 11/11 条是 0；站点楼中楼也没有点赞入口 | **不采用：没有信号、且要交互** | 同上（卡片上写一个恒为 0 的计数只是噪声） |
| 绝对时间戳 | DOM 与接口只有相对时间（`9小时前`）与 `create_at` | **不采用：DOM 口径就该是站点的** | 卡片保持站点原文 |
| 楼中楼整组一个容器 | 站点已有 `.link-comment__comment-children`（`#fafbfc` + 8px 圆角 + 10px 内边距） | **已经一致** | 不动它 |
| 卡片配色「比页面亮一档 + 1px 描边」 | 卡片层本来就是这套（见 `src/comment-cards.css` 的令牌） | **已经一致** | 不动它 |

## 3. 这一轮因此改了什么（对照代码，别只看这张表）

- `src/comment-api-cache.ts`：`ThreadReplyMeta` 多一个 `replyId`（= 响应里的 `replyid`），
  卡片层靠它把回复对象落到**具体某一张卡片**上。主楼本体没有这个字段。
- `src/comment-cards.ts`：
  - 每张卡片插一枚 `.hb-tc__floor`（`N#`，1 起，纯 DOM 位置）；
  - 回复对象三态：站点自己渲染了名字 → **一个字不动**；能在同楼定位到目标卡片 →
    「回复 #N 名字」；目标是楼主 → 「回复楼主」；接口查不到 → 保持站点原样；
  - 一级评论操作条里插 `.hb-tc__fold`，折叠只给楼中楼容器加 `hb-tc--folded`，
    按钮的 click **必须 stopPropagation**（一级评论整行是热区，不拦会顺路弹回复框）。
- `src/comment-cards.css`：序号徽标（`order` + `margin-left:auto` 落在第一行右端，
  不用绝对定位 —— 第一行本来就长，绝对定位会压住时间）、折叠按钮（与站点既有
  「回复」按钮同一套材质）、折叠态规则（本层唯一一处隐藏站点节点）。
- 序号徽标与站点紧跟其后的那个冒号之间用 `margin-right: -8px` 抵消卡片列间距，
  否则读成「回复 楼主 :」（参考页是「回复1# 独眼x巨人：」）。
- 时间/IP 换到独立一行时踩到一条 flex 规则：**换行是由「假设主尺寸」阶段决定的，
  `flex-grow` 只在分行之后分配剩余空间**。所以「让站点的 `:` 用 `flex: 1 1 auto` 吃满第一行」
  根本不换行（项已经排在同一行，grow 只是把它撑宽）；可靠做法是让时间/IP 自己
  `flex-basis: calc(100% - 41px)` **占满一行**。
